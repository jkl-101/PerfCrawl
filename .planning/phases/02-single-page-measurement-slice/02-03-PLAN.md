## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-controlled URL → subprocess argv | The URL passes from the CLI into `subprocess.run` argv for both Chrome launch and Node worker invocation; shell metacharacters in the URL must not trigger shell expansion |
| Chrome process lifecycle → host machine | The orchestrator owns a long-running Chromium subprocess; on a crash, the process must be reliably killed and the user_data_dir cleaned (DoS mitigation) |
| Worker stdout → Python normalizer | The Node worker's stdout JSON is parsed and fed into `normalize_lh`; the version gate (D-10, from 02-01) is the integrity check |
| Subprocess timeout → kernel | The Python `subprocess.run(timeout=…)` plus the worker's internal `setTimeout(() => process.exit(1), 55_000)` (from 02-01) is belt-and-suspenders against a hung Lighthouse |
