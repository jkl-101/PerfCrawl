<objective>
Build the pure-function median-of-N aggregation layer the orchestrator (02-03) will call once per measure run to collapse N per-sample PageResults into a single PageResult with `MetricSample.median` and `MetricSample.samples` populated per metric.

Phase 2 ships this so Phase 6's regression flagging stands on stable distributions from day one (per ROADMAP overview). The aggregator is a pure function over `list[PageResult]`, depending only on the Phase 1 model — independent of normalizer/orchestrator/CLI — so it can ship in parallel with 02-01.

Output: `src/perfcrawl/aggregator.py` (≈80 LOC, two functions) + `tests/test_aggregator.py` (parametrized over RUN-04 + Pitfall-3/7 + finite-guard edge cases).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Per-sample data → aggregated PageResult | The orchestrator (02-03) feeds N PageResults from N worker subprocesses into the aggregator; a hostile worker could supply inf/nan/None values that the aggregator must drop without raising |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-A | Tampering | `aggregate_samples` (inf/nan input) | mitigate | Finite-guard pattern from Phase 1 LEARNINGS — `math.isfinite()` drop before `statistics.median()`. Defense-in-depth above `MetricSample.allow_inf_nan=False` (which would reject the model on construction; the aggregator pre-filters so the model is never approached with bad data). Test `test_aggregator_drops_non_finite_samples` parametrizes over `[math.inf, -math.inf, math.nan]` |
| T-02-02-B | Denial of Service | `aggregate_samples([])` | mitigate | Pitfall 3 — `statistics.median([])` raises `StatisticsError` which would crash the orchestrator's per-page reduce step. Explicit empty-list guard returns `MetricSample(median=None, samples=[])` (D-16 honest empty). Test `test_empty_samples_median_none` |
| T-02-02-C | Tampering | `aggregate_page_samples` (URL mismatch) | mitigate | Mixing samples from different pages into one aggregate is a load-bearing bug (would silently merge two pages' metrics). Explicit `if len({s.url_key for s in samples}) > 1: raise ValueError` guard. Test `test_url_mismatch_raises` |
| T-02-02-D | Tampering | INP labeling | mitigate | `aggregate_page_samples` uses `samples[0].model_copy(update={...})` which preserves the Phase 1 `_no_bare_inp` validator path; no `inp` variable name appears in the aggregator code. The model-layer floor is intact |

ASVS coverage: V5 (Input Validation — None/inf/nan filtering, empty-list guard, URL mismatch raise), V7 (Error Handling — deterministic empty rather than crash on Pitfall 3).
