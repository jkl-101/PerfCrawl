The unit test suite hides the defect (every test mocks `subprocess.run` with small synthetic JSON), the documented e2e test was added but apparently never executed as part of the SUMMARY's self-check (it's currently red on the same machine where the unit suite is green), and the code review correctly identified CR-01 + CR-02 + CR-03 but the findings were never closed.

Three critical fixes (all already specified in `02-REVIEW.md`) will close the gap:

1. **CR-01 in `lighthouse-worker/run.mjs`:** use the callback form of `process.stdout.write(payload, callback)` so stdout drains before `process.exit(0)`. Add a regression test that round-trips a >1 MB synthetic payload through the real subprocess (not mocked). This is the load-bearing fix — without it, the phase goal is unattainable.
